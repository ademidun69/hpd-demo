Pre-flight security check for AI agents on Pharos.

HPD gives any agent the ability to evaluate the risk of an EVM smart contract before signing a transaction. It combines static bytecode analysis, onchain reputation, and behavioral simulation into a single 0–100 risk score with a clear verdict and a traceable list of findings. Fully read-only.

      THREE LAYERS

      One clean verdict from three independent checks

      01

      Static analysis

      Scans deployed bytecode for 30+ known-dangerous function selectors: hidden mint, blacklist, pause, owner withdraw, fee manipulation, proxy upgrade, selfdestruct.

      02

      Reputation & context

      Reads contract age, deployer, holder concentration, and liquidity lock status directly from the chain.

      03

      Behavioral simulation

      Forks Pharos mainnet via Anvil (Foundry), deploys a copy of the contract, and runs a buy + sell round-trip to surface runtime traps.

      SAFETY

      Read-only by design

      HPD performs analysis only. It does not request wallet signatures, does not broadcast transactions, and does not connect to user wallets. All simulations run inside an ephemeral local Anvil fork.
